# تست مرورگری (دستی) — Phase 1

چک‌لیست دستی قبل از ورود به Phase 2 (بدون ابزار خودکار، در مرورگر واقعی):

## دسکتاپ
- [ ] `http://localhost:8080/` باز می‌شود؛ Layout (Header + Footer) کامل است
- [ ] RTL صحیح: متن راست‌چین، منو در سمت درست
- [ ] Hero + ۴ کارت «به‌زودی» (مقالات، اخبار، رویدادها، گزارش‌ها)
- [ ] عنوان تب: `خانه | سایت من`
- [ ] کلیک روی «خانه» و برند → به `/` بازمی‌گردد
- [ ] مسیر تصادفی (مثلاً `/bla-bla`) → صفحه ۴۰۴ با دکمه‌ی برگشت

## موبایل (DevTools یا دستگاه واقعی)
- [ ] چیدمان Mobile-First: کارت‌ها ستونی، بدون اسکرول افقی
- [ ] اندازه‌ی فونت‌ها قابل خواندن؛ دکمه‌ها قابل لمس

## شبکه
- [ ] DevTools → Network: هیچ request با status ≥ 400 ندارد
- [ ] DevTools → Console: هیچ خطای JS/PHP نیست
