# Migrationها — دیتابیس‌های نصب‌شده با فازهای قبلی

`database/schema.sql` فقط جدول‌های نبوده را می‌سازد و جدول موجود را تغییر
نمی‌دهد. هر تغییری در ساختارِ یک دیتابیسِ از قبل نصب‌شده، یک فایل migration
جدا در همین پوشه دارد.

| فایل | هدف | برای کدام نصب‌ها |
|---|---|---|
| `2026-09-23_phase6_knowledge_types.sql` | افزودن انواع محتوای Phase 6 (book/lesson/research) به ENUM `contents` + ساخت جدول‌های `books`، `research`، `lessons` | نصب‌های Phase 2 تا 5 |

نکته‌ها:

- قبل از اجرا از کنترل‌پنل هاست یا phpMyAdmin پشتیبان بگیرید؛ shell لازم نیست.
- همه‌ی تغییرات این فایل additive است؛ هیچ داده‌ای حذف یا بازنویسی نمی‌شود.
- نصب تازه نیازی به این فایل ندارد؛ `schema.sql` ساختار نهایی را می‌سازد.

## هویت سایت

`2026-09-23_site_settings.sql` جدول سبک تنظیمات را ایجاد می‌کند. Installer نصب جدید آن را از runner مشترک `app/Helpers/migrations.php` اجرا/ثبت می‌کند. نصب قدیمی از `POST /admin/settings/upgrade` (admin + CSRF) ارتقا می‌یابد؛ قفل نصب و حساب‌ها حفظ می‌شوند. خواندن تنظیمات هرگز migration اجرا نمی‌کند.

Migration اجراشده را ویرایش نکنید؛ checksum آن بررسی می‌شود. فایل جدید اضافه کنید. برای جزئیات به `docs/BRANDING-AND-INSTALLER.md` مراجعه کنید.
